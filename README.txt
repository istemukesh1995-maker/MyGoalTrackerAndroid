MY GOAL TRACKER — ANDROID PROJECT
===================================
This is an Android Studio project source, not a precompiled APK.

Build an APK:
1. Install Android Studio on a computer.
2. Open the MyGoalTrackerAndroid folder in Android Studio.
3. Allow Gradle sync and install Android SDK Platform 35 if prompted.
4. Use Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location (usually app/build/outputs/apk/debug/app-debug.apk).
6. Transfer the APK to your Android phone and open it. You may need to allow installation from that source.

App features:
- Five goals: ₹1 crore wealth, ₹50 lakh land, Hyundai Creta, Yamaha FZ-S, 1 tola gold.
- Add deposits, view progress and history, edit target/existing savings.
- Export contribution history to CSV.
- Data stored locally on the device; no account sync or financial-account connection.

Important:
- The targets/daily guide figures are initial planning estimates. Review and edit them to match your own spreadsheets.
- The app is not connected to banks, Zerodha, or mutual funds.
- Uninstalling or clearing app data may remove saved data. Export CSV backups.
